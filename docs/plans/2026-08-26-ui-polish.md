# ScaleAi UI 优化三项需求 实现计划

> **分支:** feat/ui-polish（基于 feat/three-enhancements 创建）
> **目标:** 完成三项 UI/交互优化需求

## 需求总览

1. **页面永久禁止翻转** — 全 App 锁定竖屏
2. **同步失败才弹窗手动输入** — 移除常驻手动输入，仅同步失败时弹窗
3. **历史图改单轴体脂率** — Y轴=体脂率(%)、X轴=日期、折点可点击查看数值

---

## 需求 1：页面永久禁止翻转

**现状:** `AndroidManifest.xml` 的 MainActivity 未声明 screenOrientation，默认允许旋转。

**改法:** 在 `app/src/main/AndroidManifest.xml` 的 `<activity android:name=".MainActivity">` 增加属性：
```xml
android:screenOrientation="portrait"
```
同时建议加 `android:configChanges="orientation|screenSize|keyboardHidden"` 避免旋转时重建 Activity（可选，但锁定竖屏后旋转不再发生，此项非必需）。

**验证:** 模拟器旋转屏幕，界面保持竖屏不翻转。

## 需求 2：同步失败才弹窗手动输入

**现状:**
- `ScaleScreen.kt` 的 `IdleContent` 常驻显示"或手动输入体重"输入框 + "保存手动记录"按钮
- `ScaleViewModel.startBleSession()` 中 `sessionManager.startSession()` 返回 null → 直接进 `ScalePhase.Timeout`（"称重会话超时"）

**目标:**
- 移除 Idle 页常驻的手动输入区块（OutlinedTextField + 保存按钮）
- 点击"开始同步秤数据"后，若**同步失败/超时**（`startSession()` 返回 null）→ 弹出 AlertDialog："同步失败，是否手动输入体重？"
- 用户在弹窗内确认后，弹窗内输入体重 → 保存

**改动文件:**

### 2a. `ScaleViewModel.kt`
- 新增一个状态阶段 `ScalePhase.SyncFailed`（或在现有 Timeout 上扩展），用于触发"同步失败弹窗"
- `startBleSession()` 中 `startSession()` 返回 null 时：进入 `ScalePhase.SyncFailed`（带 message="同步失败，未获取到数据"），**不再直接进 Timeout**
- 新增方法 `saveManualFromDialog(weightText: String)`：复用现有 `startManualEntry` 逻辑（校验 + 选人 + 保存），供弹窗确认后调用
- 保留 `startManualEntry` 或重构为弹窗专用入口

### 2b. `ScaleScreen.kt`
- `IdleContent` 移除"或手动输入体重"区块（OutlinedTextField + 保存手动记录按钮），只保留"开始同步秤数据"按钮 + 提示文字
- 新增 `SyncFailedDialog`：当 `state.phase == ScalePhase.SyncFailed` 时显示
  - AlertDialog 标题："同步失败"
  - 文案："未获取到体脂秤数据，是否手动输入体重？"
  - 弹窗内放一个体重输入框（OutlinedTextField）
  - 按钮：确定（保存手动记录）/ 取消（返回 Idle）

**验证:** 模拟器点击同步（无秤）→ 超时后弹出"同步失败"弹窗 → 输入体重保存 → 走确认选人流程。

## 需求 3：历史图改单轴体脂率

**现状:**
- `HistoryScreen.kt` 使用 `DualAxisChart(weights, bodyFatPcts)` 画"体重/体脂率"双轴图
- `DualAxisChart.kt` 是双 Y 轴（左体重、右体脂），无日期标签、无点击交互
- `TrendLineChart.kt` 是简单单线图，无标签、无点击

**目标:**
- 改成**单轴体脂率折线图**（去掉体重线）
- **Y轴** = 体脂率(%)，带刻度标签
- **X轴** = 日期（MM-dd），带刻度标签
- **折点可点击**：点击某个数据点 → 弹出/显示该点的具体数值（日期 + 体脂率 + 体重）

**改动文件:**

### 3a. `DualAxisChart.kt` → 重构为 `BodyFatChart.kt`（或原地改造）
- 保留体脂率线（`bodyFatPcts`），删除体重线逻辑
- 增加：
  - Y 轴刻度标签（若干档：最大/最小/中间值），显示 %
  - X 轴日期标签（取若干采样点显示 MM-dd）
  - 折点可点击（用 `pointerInput` + `detectTapGestures` 检测点击位置，最近点高亮 + 显示数值）
  - 选中的点显示 tooltip/标注框（日期 + 体脂率值 + 体重值）
- 函数签名建议改为：
  ```kotlin
  @Composable
  fun BodyFatChart(
      bodyFatPcts: List<Double?>,
      dates: List<String>,        // X 轴日期标签（MM-dd，时间正序，与 bodyFatPcts 一一对应）
      modifier: Modifier = Modifier,
      ...
  )
  ```
  如需展示体重可在点击标注里带上（从 HistoryScreen 传 `weights` 作为点击详情）。

### 3b. `HistoryScreen.kt`
- 用 `BodyFatChart` 替换 `DualAxisChart`
- 准备 `dates`（从 measurement.timestamp 格式化 MM-dd）
- 标题改为"体脂率趋势"，副标题"Y轴:体脂率(%) X轴:日期"
- 图表高度可适当加大

### 3c.（可选）删除或保留 `TrendLineChart.kt`
- 若不再使用可删除；若无引用保留无害。建议保留（可能别处用）。

**验证:** 历史页显示体脂率单轴图，X轴有日期，点击折点弹出该点数值。
